= Agent Onboarding — Aden

[IMPORTANT]
====
Read this document before starting any work in this repository.
====

== Quick Start

[source,bash]
----
# 1. Read shared context
cat .agent/context.adoc    # Project constraints and conventions
cat .agent/session.adoc    # Who else is working and on what?

# 2. Understand the codebase
#    Aden is available as a context tool on its own source:
aden ask "What does <module> do?"
aden asm --from <anchor> --depth 2
aden locate --symbol <name> .

# 3. Make your change, run tests
cargo test --workspace

# 4. Log your session
echo "| $(date -u +%Y-%m-%dT%H:%M:%SZ) | <your-id> | <task> | <files> | completed |" >> .agent/session.adoc
----

== Context Tools

Aden builds a traversable knowledge graph from source code and documentation,
enabling focused context assembly for any codebase it's run against.

[cols="1,2"]
|===
|Goal |Command

|Ask a natural language question
|`aden ask "<question>"`

|Assemble focused context for an anchor
|`aden asm --from <anchor> --depth 2`

|Find a symbol definition
|`aden locate --symbol <name> .`

|Full-text search
|`aden search "<term>" .`

|Explore graph dependencies
|`aden query --from <anchor> --depth 2`

|List all indexed anchors
|`aden list .`

|Check drift between source and graph
|`aden heal .`

|Check knowledge graph health
|`aden status .`
|===

== Session Protocol

Before you start:

. Append a row to `.agent/session.adoc` with your task and status `in_progress`.

When you finish:

. Update your row to `completed` and note what changed.

== Emergency Procedures

[cols="1,2"]
|===
|Situation |Action

|Broken `<<refs>>` after rename
|`aden search "old_name"` to find references, update them.

|Another agent modified the same file
|Stop. Re-read their session entry, resolve manually.

|Drift detected after your changes
|`aden heal .` to identify stale contracts.
|===
