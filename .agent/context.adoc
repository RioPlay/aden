== What Aden Is

Aden is a **codebase-agnostic context harness**. It parses any source tree into a
traversable knowledge graph and assembles maximally dense, LLM-ready context from it.
It does not impose its own conventions on codebases it indexes — it reads and graphs
what is already there.

== Hard Constraints

. **Never commit secrets**, credentials, or private keys.
. **Never emit files outside the working directory** without explicit confirmation.
. **Never ignore test failures** — a failing test is a signal, not noise.
. **Never commit generated build artifacts** — `contracts/`, `.aden/`, `target/`.
. **Never assume Cargo/Rust structure when working on the aden CLI** — aden is
  designed to handle any language and any directory layout.

== Language Defaults

- Primary language: Rust Edition 2021/2024
- Error handling: `thiserror` for error enums
- Serialization: `serde` + `serde_json`
- All public types must have `#[derive(Debug)]` and doc comments

== Key Crates

|===
|Crate |Responsibility

|aden-core |Schema: Document, Block, Edge, Symbol, merge engine
|aden-parse |Language routers and AST extraction (Rust, Python, Go, TS/JS, C#, Java, Kotlin, PHP, Ruby, + generic fallback)
|aden-emit |Deterministic AsciiDoc and ADG emitter
|aden-graph |DiGraph, typed edges, integrity checks, cycle detection
|aden-asm |Context assembler: BFS traversal, token budgeting, LLM output
|aden-index |Full-text search with fuzzy matching
|aden-heal |Drift detection and health scoring
|aden-propose |Patch generation and proposal lifecycle
|aden-mcp |MCP server (JSON-RPC over stdio)
|aden-policy |Constitutional policy engine
|aden-cli |Binary (`aden`) with all subcommands
|===

== Context Tools

Since aden is self-hosting, you can use it on its own source:

[source,bash]
----
aden ask "How does context assembly work?"
aden asm --from mod-aden-asm --depth 2
aden locate --symbol assemble .
aden search "token budget" .
----
