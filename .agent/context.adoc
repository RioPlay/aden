= Shared Context — aden

This file is the canonical shared memory for all agent sessions on `aden`.

== Project Identity

[cols="1,2"]
|===
|Name |aden — A Dense Referential Context Compiler
|Primary Language |Rust (edition 2024)
|Runtime / Build |cargo
|License |AGPL-3.0-or-later
|Structure |Cargo workspace, 18 crates
|===

aden turns any codebase or document corpus into a queryable, attributed,
token-dense knowledge graph: it extracts symbols, call graphs, and references,
materializes them into a persistent store, and assembles focused context for
LLM agents. See `docs/architecture.adoc` and `.agent/glossary.adoc`.

== Hard Constraints

. **Never commit secrets**, credentials, or private keys.
. **Never emit files outside the working directory** without explicit confirmation.
. **Never ignore test failures** — a failing test is a signal, not noise.
. **Never commit generated build artifacts** (e.g. .aden/, target/, node_modules/).
. **Always read existing code** before writing new code in the same area.

|===

=== External dependencies (key)

- `tree-sitter` + `tree-sitter-language-pack` — multi-language parsing
  (grammars compiled statically; see `CONTRIBUTING.md`).
- `fjall` — embedded LSM key-value store backing `aden-store`.
- `petgraph` — in-memory graph representation.
- `clap` — CLI argument parsing.
- `rmcp` — Rust MCP SDK for the `aden-mcp` server.
- `tower-lsp` — LSP server framework for `aden-lsp`.
- `serde` / `serde_json` — serialization.

A full third-party license inventory lives in `NOTICE.md`.

== Context Tools

If aden is installed, it can assemble focused context from the knowledge graph:

[source,bash]
----
aden ask "<question>"               # natural language query
aden asm --from <anchor> --depth 2  # focused context assembly
aden locate --symbol <name> .       # find a symbol
----

Aden is supplemental. The authoritative source of truth is always the source
code and tests in this repository.
