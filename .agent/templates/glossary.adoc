= Project Glossary

Aden:: The context compiler. Extracts structural knowledge from source code and turns it into a traversable, token-dense graph.
Assembly:: A single `.adoc` file containing assembled context (contracts, edges, backlinks) for a specific symbol or query.
Anchor:: A globally unique AsciiDoc identifier matching `^[a-z0-9_-]+$`. Every contract must declare one.
Block:: A content unit within a Document: `Table`, `Paragraph`, `Listing`, `Admonition`, or `DescriptionList`.
Call Site:: A location in source code where one function invokes another. Extracted and emitted as `edge::calls[callee]`.
Contract:: A `.adoc` or `.aden` file describing an API surface, behavior, or architecture. Generated by `aden gen`, never committed.
Dependency Graph:: A directed graph of symbols and their `Edge` relationships. Built by `aden graph`.
Drift:: Divergence between source code reality and generated contracts. Detected by `aden heal`.
Edge:: Typed relationship between two Documents (e.g., `calls`, `depends`, `includes`, `backlinks`).
Emitter:: The `aden-emit` crate that serializes Documents into AsciiDoc text.
Extraction:: Parsing source code into a `Vec<Document>`.
Filter:: Rules that determine which files are scanned or excluded. Supports `.adenignore` and `.adenallow`.
Health Score:: Float from 0.0 to 1.0 computed by `aden heal`. 1.0 means zero drift.
ProfileMode:: Aden config setting: `internal` (default, full fidelity) or `public` (redacted for sharing).
Proposal:: A `.patch.adoc` file generated by `aden heal --propose`, suggesting contract changes.
SourceSpan:: Precise file location: `{file, start_line, end_line, start_byte, end_byte}`.
Symbol:: A named entity extracted from source code (function, type, trait, module, field).
Stub:: An auto-generated `.aden` contract with `agent-note::STUB` requiring human review.
Token Density:: The ratio of useful semantic tokens to total characters. Aden optimizes for high density.
agent-note:: An AsciiDoc admonition block (`NOTE`, `WARNING`, `TODO`) containing temporal metadata or uncertainty.
