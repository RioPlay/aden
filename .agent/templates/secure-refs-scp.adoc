[[secure-refs-scp]]
= OWASP Secure Coding Practices — Category Index

The OWASP Secure Coding Practices Quick Reference Guide organizes controls into
the categories below. Only the category names are listed here (with aden's own
gloss); the full checklist items are in the OWASP guide — see
<<secure-refs-sources>>. For aden's own enforceable standard, see
<<secure-coding>>.

[[scp-ref-input-validation]]
== Input Validation
Validate untrusted input on the trusted side before use.

[[scp-ref-output-encoding]]
== Output Encoding
Encode data for its destination context so data is never read as code.

[[scp-ref-auth]]
== Authentication & Password Management
Verify identity and store credentials safely.

[[scp-ref-session]]
== Session Management
Issue, protect, and expire session state correctly.

[[scp-ref-access-control]]
== Access Control
Enforce authorization on every privileged action.

[[scp-ref-crypto]]
== Cryptographic Practices
Use vetted algorithms and manage keys/randomness correctly.

[[scp-ref-error-logging]]
== Error Handling & Logging
Fail safely; log security events; never log secrets.

[[scp-ref-data-protection]]
== Data Protection
Minimize, protect, and segregate sensitive data.

[[scp-ref-comms]]
== Communication Security
Protect data in transit (TLS, certificate validation).

[[scp-ref-sysconfig]]
== System Configuration
Harden runtime configuration and remove debug surface.

[[scp-ref-db]]
== Database Security
Use parameterized queries and least-privilege DB accounts.

[[scp-ref-file-mgmt]]
== File Management
Validate, confine, and de-privilege file handling.

[[scp-ref-memory]]
== Memory Management
Bound buffers; free correctly; scrub sensitive memory.

[[scp-ref-general]]
== General Coding Practices
Use vetted libraries; avoid dynamic execution of untrusted input.
