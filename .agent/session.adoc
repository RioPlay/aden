= Agent Session Log

== Purpose
This file is the canonical shared memory for parallel subagent sessions. Every agent that modifies files must append an entry here before completing. This prevents race conditions and silent overwrites.

== Format
Each entry is a table row with timestamp, agent ID, action, files touched, and blockers.
