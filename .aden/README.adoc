= Legacy Repository Configuration

== What remains here
This repository retains its previously tracked constitution and sample hooks.
The constitution is optional project policy loaded by Aden; the hook files are
inactive examples unless explicitly installed. `NOTICE.md` is historical
attribution guidance, not the release's third-party notice.

== Generated state
The graph store and caches live in the per-user data directory, outside the
checkout. `.gitignore` also excludes new `.aden` contents, legacy contracts,
snapshots and locks if an older tool creates them locally. Existing tracked
configuration remains tracked; ignoring a directory does not untrack files.

== Release files
The maintained license and attribution files are `LICENSE` and `NOTICE.md` at
the repository root. Release bundles contain those files, not this directory.
