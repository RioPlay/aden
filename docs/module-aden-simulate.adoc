Graph history and evolution tracking. Allows simulation of graph state changes, diffs across git history, and "what-if" analysis.

== Status

== Intended Features

|===
|Feature |Description

|`aden history --evolve`|Graph diff across Git history.
|`simulate_graph`|Run hypothetical changes and see impact.
|`diff_contracts`|Show semantic diff between contract versions.
|===
