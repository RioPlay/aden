= Phase 5: Ecosystem & Distribution

== Objective
Turn Aden from a CLI into a multi-tool platform: semantic search, IDE integration, language bindings, file watchers, benchmarks, and publish-ready packaging.

== Constraints
:idempotent: true
:rollback: false

== Deliverables
|===
|Module |Deliverable |Acceptance Criteria

|aden-index |Semantic search |`aden search "<query>"` returns ranked anchors with snippets
|aden-lsp |LSP server |Diagnostics + go-to-definition for `.adoc`/`.aden`
|editors/vscode |Extension skeleton |Launches LSP, provides outline
|aden-py |PyO3 bindings |`import aden; aden.generate(path)` works
|tools/ps-adapter |PowerShell module |`Invoke-AdenAssemble`, `Test-AdenIntegrity`
|aden-cli |`aden watch` |`notify`-based file monitoring + auto-regeneration
|benches/ |Benchmark suite |Token density, graph construction, assembly timing
|repo |Distribution prep |README, CI, crates.io metadata
|===
