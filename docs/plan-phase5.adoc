[[plan-phase5]]
= Phase 5: Production Feedback Loop (Weeks 11–14)

== Objective

The constitution learns from runtime reality.

== Theme

Telemetry-driven contract evolution, simulation, and adversarial testing.

== Deliverables

|===
|ID |Deliverable |Crate |Status |Acceptance Criteria

|5.1 |OTLP trace ingestion |`aden-telemetry` |Planned |Accepts spans from OpenTelemetry collector; maps to contract nodes via `.adg` IDs
|5.2 |Telemetry proposal engine |`aden-telemetry` |Planned |Guard firing → proposes `[security]` update; latency spike → proposes `[agent#perf]` directive
|5.3 |`aden simulate --diff` |`aden-simulate` |Planned |Shows future contract violations before commit; developer can abort or fix
|5.4 |`aden history --evolve` |`aden-simulate` |Planned |Graph diff across Git history; reports edge growth/shrink and override density per module
|5.5 |`aden fuzz-contract` |`aden-simulate` |Planned |Generates adversarial code; flags brittle directives (e.g., missing `:transitive:`); suggests hardening
|5.6 |`aden cost-report` |`aden-telemetry` |Planned |Token savings vs. schema-loading baseline; exports CSV for CFO dashboards
|5.7 |Confidence score updates from telemetry |`aden-policy` |Planned |Historical accuracy of `[agent]` directives updated automatically; low-confidence agents flagged
|===

== Exit Gate

Security incident automatically correlates with contract state, proposes `[forbid_import]`, and post-mortem includes `aden history` of affected module.
