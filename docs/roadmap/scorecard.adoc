= Aden Program Scorecard

The program control loop runs after every landed packet and at milestone review.
It observes results, reconciles GitHub and repository state, reprioritizes work,
unlocks satisfied dependencies, and dispatches the smallest high-value packet.
Its authority is limited to milestone measurement; see <<roadmap-authority>> for
the complete record-role map.

[cols="2,2,3"]
|===
|Dimension |Gate |Evidence

|Context completeness
|100% of eligible files accounted for
|Persisted disposition manifest and adversarial fixtures

|Freshness correctness
|100% of authoritative-state scenarios correct
|Revision/fingerprint integration matrix

|Budget compliance
|Serialized output within requested budget and documented tolerance
|CLI/MCP property and golden tests

|Interface parity
|100% of public read tools accounted for
|Schema, error, default, and semantic parity fixtures

|Downstream quality
|No correctness regression before optimization
|With/without-Aden task evaluation
|===

After each milestone, compare estimated and actual effort, record repeated
blockers, prune invalid future packets, update packet templates, and revise gates
only through an explicit decision record.
