[[aden-program]]
= Aden Improvement Program

This is the authoritative execution program for Aden's long-term improvement.
It turns product findings into dependency-ordered work packets that humans and
agents can execute without losing the reasoning behind them.

GitHub owns live assignment, discussion, and review. These documents own scope,
dependencies, acceptance criteria, compatibility constraints, and final evidence.
When the two disagree, the packet contract in this directory wins.

== North-star contract

Given a question or proposed change, Aden returns the smallest sufficient
context, proves where it came from, states what may be missing, and verifies the
consequences.

== Control loops

[source,text]
----
PROGRAM: Observe -> Score -> Reconcile -> Prioritize -> Unlock -> Dispatch -> Measure
PACKET:  Discover -> Claim -> Baseline -> Implement -> Verify -> Review -> Land -> Learn
----

A landed change is not done until its promised outcome is measured.
