= LG-105: Roadmap source-of-truth migration

== Outcome

Future work, shipped behavior, durable decisions, and historical findings cannot
silently contradict each other.

== Acceptance

* This program owns executable future work.
* ADRs own decisions and `CHANGELOG.md` owns shipped deltas.
* Historical issue and remediation material is labeled and linked, not duplicated.
* Living state carries an `as-of` release or commit and supersession link.

== Non-goals

Do not delete historical evidence or rewrite accepted ADR rationale.

== Failure modes and rollback

Migration may break old references. Preserve anchors, add aliases where needed,
and validate with `aden check . --severity Forbid`.
