= AP-000: Minimal execution control plane

== Outcome

Focused agents can discover, claim, validate, review, and complete independent
work without conflicting authority or silent dependency drift.

== Current evidence

Roadmap state is spread across `ISSUES.md`, `AUDIT_REMEDIATION_PLAN.md`, ADRs,
architecture documents, and `CHANGELOG.md`. No machine check validates packet
IDs, dependencies, states, or declared change surfaces.

== Scope

The documents under `docs/roadmap/`, their validator, CI validation, and GitHub
issue hierarchy. Live claim state remains in GitHub.

== Non-goals

No scheduler, bot, runtime Aden changes, or automatic issue mutation.

== Acceptance

* Program and packet loops, authority, leases, evidence, and pruning are documented.
* Every packet has unique metadata and an acyclic dependency graph.
* CI runs the validator.
* Active packets have one mirrored GitHub issue.

== Failure modes and rollback

If maintenance cost exceeds ten percent of milestone work, retain completed
evidence, archive active state, and replace coordination without changing product code.

== Completion evidence

Validator output, CI result, linked issues, independent review, and clean diff check.
