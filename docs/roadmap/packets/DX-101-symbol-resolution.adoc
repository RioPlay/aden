[[dx-101]]
= DX-101: Natural symbol resolution

== Outcome

Developers and agents can use ordinary qualified symbol forms without copying
opaque graph anchors or spelling generic parameters exactly.

== Acceptance

* `AdenGraph::bfs` resolves canonical `AdenGraph<N, E>::bfs` fixtures.
* More than 95% of canonical-equivalent whitespace/generic/qualified forms resolve.
* Ambiguity returns ranked candidates with no silent wrong selection.
* Recovery recommends `locate` instead of a broad repository listing.

== Non-goals

No conceptual retrieval redesign.

== Failure modes and rollback

Prefer explicit ambiguity over a convenient incorrect match. Keep exact-anchor
resolution as the deterministic escape hatch.
