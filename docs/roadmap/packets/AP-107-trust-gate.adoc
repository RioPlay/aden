= AP-107: Trust integration gate

== Outcome

The Trust Foundation works as one measured system and safely unlocks outcome
evaluation. This packet introduces no new product behavior.

== Acceptance

* Adversarial tests cover credential-like content, stale/failed refresh, output
  truncation, unsupported files, advisory findings, CLI/MCP comparison, and
  working-tree mutation during a query.
* Receipts never expose secrets and coverage arithmetic reconciles.
* Trust scorecard gates pass without regression.
* A dogfood run records developer and agent outcomes at E4.

== Failure modes and rollback

Any failed gate keeps later milestones locked. Fix the owning packet rather than
adding behavior here.
