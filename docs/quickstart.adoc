= Quickstart: Using Aden as an AI Agent

This document helps AI agents understand how to use Aden effectively.

== How Aden Works

Aden transforms your codebase into a navigable knowledge graph. Each function, module, and decision becomes a node. Relationships (imports, calls, constraints) become typed edges.

== Essential Commands for AI Agents

|===
|Goal|Command

|Generate contracts|`aden gen .`
|Find anchors|`aden list .`
|Ask a question|`aden ask "<question>"`
|Fix drift|`aden heal . --fix`
|Cleanup|`aden heal . --gc`
|Get help|`aden suggest "<what I want to do>"`
|===

== Example Workflow

[source]
----
# 1. Discover what's available
aden list . --limit 10

# 2. Ask a question
aden ask "how does auth work?" --from mod-aden-core

# 3. Get context for a specific function
aden asm --from aden://module/aden-graph/graph.rs#AdenGraph --depth 2

# 4. Fix any drift
aden heal . --fix
----

== Anchor Patterns

- `mod-<crate>` - Module overview (e.g., `mod-aden-cli`)
- `aden://module/<path>#<symbol>` - Specific function/type
- `plan-*` - Project plans
- `adr-*` - Architecture decisions

== Troubleshooting

|===
|Error|Solution

|MissingAnchor|Run `aden list .` to find valid anchors
|StaleHash|Run `aden heal . --fix`
|No results|Try `aden search "<keyword>"`
|===

== For More Help

- `aden doctor .` - Check environment
- `aden suggest "<intent>"` - Get command suggestions
- `aden check .` - Validate references
