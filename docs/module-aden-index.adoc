= module::aden-index

== Objective
Semantic and full-text search over the Aden knowledge graph using an in-memory inverted index.

== Signature
|===
|Type/Function |Signature |Description

|`SearchResult`|struct|anchor, source_path, score, snippet
|`Index`|struct|In-memory inverted index
|`from_directory`|`pub fn from_directory(dir: &Path) -> Result<Index, io::Error>`|Build index from all `.adoc`/`.aden` files under dir
|`query`|`pub fn query(&self, query_str: &str) -> Vec<SearchResult>`|Tokenizes query, scores by TF, ranks descending, generates snippet
|`tokenize`|`pub fn tokenize(text: &str) -> Vec<String>`|Lowercase, strip punctuation, filter stop words
|===

== Invariants
. Anchors, attribute keys/values, table cells, and description-list terms are all indexed.
. Stop words are filtered during both indexing and querying.
. Snippets return the first line containing a query token, truncated to 200 chars.
. Non-`.adoc`/`.aden` files are silently skipped.

== Agent Notes
agent-note::SIMPLIFICATION
No BM25, no stemming, no phrase queries. Pure inverted index with term-frequency scoring. Sufficient for agent-scale repos (<10k documents).
