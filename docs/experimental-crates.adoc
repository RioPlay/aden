|===

== Core Crates (Fully Integrated)

These crates are **actively used** and form the core aden functionality:

- `aden-core` - Schema and types
- `aden-parse` - Language parsers
- `aden-emit` - Contract emission
- `aden-graph` - Knowledge graph
- `aden-index` - Full-text search
- `aden-asm` - Context assembly
- `aden-cli` - Main binary
- `aden-mcp` - MCP server
- `aden-heal` - Self-healing
- `aden-propose` - Patch generation (used by heal)
- `aden-policy` - Constitutional directives

== Governance

New crates should start as:
1. Features in existing crates (preferred)
2. Experimental crates with clear integration path
3. Standalone crates only with strong justification

Experimental crates older than 12 months without integration plans should be:
- Archived to separate repos, or
- Removed from the codebase
