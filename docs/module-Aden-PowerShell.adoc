[[mod-Aden-PowerShell]]
= module::Aden-PowerShell

== Objective
PowerShell module wrapping the Aden CLI for idiomatic Windows/admin usage.

== Signature
|===
|Cmdlet |Args |Behavior

|`Invoke-AdenGenerate`|`-Path <str> [-OutDir <str>]`|Calls `aden gen` with optional `--out-dir`
|`Invoke-AdenAssemble`|`-From <str> -Path <str> [-Depth <int>] [-Budget <int>]`|Calls `aden asm`
|`Test-AdenIntegrity`|`-Path <str>`|Calls `aden check`; returns `$true`/`$false`; captures stderr
|===

== Invariants
. All cmdlets validate mandatory parameters.
. `Test-AdenIntegrity` uses `Start-Process` with redirected stderr to capture errors.
. `Invoke-AdenAssemble` maps `-Depth` and `-Budget` to `--depth` and `--budget` flags only when present.
