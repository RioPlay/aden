== Project Glossary

Document:: The atomic node in the Aden knowledge graph. Has an anchor, a node type, attributes, and blocks.
Edge:: Typed relationship between two Documents. Enforced by `aden-graph`.
Contract:: A table block within a Document describing an API surface or behavioral guarantee.
Block:: A content unit within a Document: table, paragraph, listing, admonition, or description list.
Symbol:: A named entity extracted from source code (function, type, trait, module).
Anchor:: A globally unique AsciiDoc identifier matching `^[a-z0-9_-]+$`.
Emitter:: The `aden-emit` crate responsible for serializing `Document` structs into `.adoc` / `.aden` text.
Extraction:: The process of parsing source code (Rust, Python, PowerShell) into a `Vec<Document>`.
ContractRegion:: Semantic region of a contract (`Generated`, `Human`, `Agent`, `Security`, `Contract`, `Constitution`, `Override`, `Proposed`). Determines merge behavior.
ContractState:: Three-way merge state (`ground`/`base`/`working`) for incremental contract generation.
Constitution:: A `[constitution]` block containing precedence-ranked policy directives. The highest authority in the contract hierarchy.
Directive:: A policy rule (`Forbid`, `Warn`, `Suggest`, `Allow`) extracted from `[security]` or `[constitution]` blocks.
Override:: A `[override]` block that bypasses a directive with `:justification:` and `:reviewer:`.
Staging:: Write-only audit trail in `.aden/staging/` for agent proposals before promotion.

== Agent Conventions

. Every `.adoc` file must declare an anchor immediately before the title.
. Every table must have a header row.
. Use `agent-note::` blocks for temporal annotations and uncertainty.
. Use `ifdef::agent[]` to hide human prose from AI context.
. Never use YAML frontmatter; use AsciiDoc attributes (`:key: value`).
. Resolve every `<<reference>>` to an existing `[[anchor]]`.
. Include this file rather than duplicating definitions.
