= module::aden-core

== Objective
Universal schema for the Aden referential context compiler.

== Signature
|===
|Type |Kind |Description

|`Document`|struct|Root node in the graph. Has `anchor`, `node_type`, `attributes`, `blocks`.
|`Block`|enum|Content block: `Table`, `Paragraph`, `Listing`, `Admonition`, `DescriptionList`.
|`Table`|struct|Rows + columns. Must support header row.
|`Symbol`|struct|Named entity extracted from source code.
|`FunctionSig`|struct|Name, parameters, return type, visibility.
|`TypeDef`|struct|Name, kind, fields, trait bounds.
|`Contract`|struct|Invariants, side effects, error conditions.
|`Edge`|struct|`(source_anchor, target_anchor, edge_type)`.
|`EdgeType`|enum|Strict enumeration: `Uses`, `Implements`, `Tests`, `Documents`, `Constrains`, `Justifies`, `Invokes`, `Requires`, `Mutates`, `Calls`, `Supersedes`, `Amends`, `Verifies`.
|`Error`|enum|Unified error type via `thiserror`.
|===

== Invariants
. Every `Document` must have a globally unique `anchor`.
. Every `anchor` must match regex `^[a-z0-9_-]+$`.
. `attributes` must contain at least `:source_hash:` if emitted from code.
. All public types derive `Debug`, `Clone`, `Serialize`, `Deserialize`.
. This crate has no dependencies on parsing or I/O.
