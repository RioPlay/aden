= module::aden-core

== Objective

Universal schema for the Aden referential context compiler. This crate is the load-bearing foundation for all other crates and has no dependencies on parsing, I/O, or emission logic.

== Signature

|===
|Type |Kind |Description

|`Document`|struct|Root node in the graph. Has `anchor`, `node_type`, `attributes`, `blocks`, `metadata`.
|`Block`|enum|Content block: `Table`, `Paragraph`, `Listing`, `Admonition`, `DescriptionList`, `Checklist`.
|`ChecklistItem`|struct|Checkbox item with `checked` bool and `text` string.
|`Table`|struct|Rows + columns. Must support header row.
|`Symbol`|struct|Named entity extracted from source code.
|`FunctionSig`|struct|Name, parameters, return type, visibility.
|`TypeDef`|struct|Name, kind, fields, trait bounds.
|`Contract`|struct|Invariants, side effects, error conditions.
|`Edge`|struct|`(source_anchor, target_anchor, edge_type)`.
|`EdgeType`|enum|Strict enumeration: `Uses`, `Implements`, `Tests`, `Documents`, `Constrains`, `Justifies`, `Invokes`, `Requires`, `Mutates`, `Calls`, `Supersedes`, `Amends`, `Verifies`.
|`Error`|enum|Unified error type via `thiserror`.
|`ContractRegion`|enum|Semantic region: `Generated`, `Human`, `Agent`, `Security`, `Contract`, `Constitution`, `Override`, `Proposed`.
|`RegionBlock`|struct|A block inside a `ContractDocument` with region, tag, attributes, and content.
|`ContractDocument`|struct|Region-aware document with `header_attrs`, `blocks`, and `prose`.
|`ContractState`|struct|Three-way merge state: `ground`, `base`, `working`.
|`MergeAction`|enum|`UpdateGenerated`, `PreserveHuman`, `Conflict`, `InsertGenerated`, `DeleteGenerated`.
|`MergeProposal`|struct|Result of a dry-run merge with counts per action type.
|`ParseMode`|enum|`Strict` (CI-enforced, line-specific errors) or `Permissive` (authoring-friendly, warns but never fails).
|`SourceSpan`|struct|File location: 1-based line range, 0-based byte offsets.
|`DocumentMetadata`|struct|Document-level metadata: `author`, `email`, `revision`, `version`, `date`, `copyright`, `license`.
|`ProfileMode`|enum|`Internal` (full fidelity) or `Public` (redacted fields, hidden private dirs).
|`AdenConfig`|struct|Runtime profile loaded from `aden.toml`.
|`LicenseInfo`|struct|Third-party dependency and license metadata.
|`ThirdPartyNotice`|struct|Machine-readable notice of all third-party dependencies.
|`StagingEntry`|struct|Subagent proposal before promotion.
|`StagingManager`|struct|Handles `.aden/staging/` directory: write, list, load.
|===

== Invariants

. Every `Document` must have a globally unique `anchor`.
. Every `anchor` must match regex `^[a-z0-9_-]+$`.
. `attributes` must contain at least `:source_hash:` if emitted from code.
. All public types derive `Debug`, `Clone`, `Serialize`, `Deserialize`.
. This crate has no dependencies on parsing or I/O.
. `ContractState::apply()` never modifies human-owned blocks.

== Agent Notes

agent-note::RESOLVED
`Edge` types are locked to enum for referential integrity. Open strings rejected in ADR-001.
