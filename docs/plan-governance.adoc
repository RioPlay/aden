= Governance System: Tiered AI Alignment with Token Budgeting

== Objective
Make structural checks mandatory and cheap; semantic checks sampled and bounded. Prevent parallel agent conflicts via atomic session locking.

== Constraints
:compile_gate: true
:check_gate: true
:heal_scan_changed_only: true
:semantic_review_threshold: 0.85
:impact_review_backlink_count: 10
:semantic_review_budget_per_session: 10000

== Deliverables
|===
|Module |Deliverable |Acceptance Criteria

|aden-cli |Policy parser |Reads `.aden/policy.adoc`, configures gate behavior
|aden-cli |`--since` flag |Git incremental scanning for heal/review
|aden-cli |`aden review` command |Token-capped semantic validation
|aden-cli |Session lock protocol |Atomic append to `.agent/session.adoc`
|CI |Three-tier gates |compile-and-structure + semantic-review jobs
|===

== Tier 1: Compile-Time Gates
- `cargo build --workspace`
- `aden check --strict`
- Pre-commit hook

== Tier 2: Incremental Structural Scan
- `aden heal --since HEAD~1`
- Only changed files scanned
- Auto-applies confidence >= 0.95

== Tier 3: Semantic Review
- Triggered when confidence < 0.85 OR backlink count > 10
- Budget: 2048 tokens per review
- Emits `.patch.adoc` for human approval
