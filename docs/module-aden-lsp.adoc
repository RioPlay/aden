[[mod-aden-lsp]]
= module::aden-lsp

== Objective
Language Server Protocol implementation for `.adoc`/`.aden` files. Provides diagnostics, go-to-definition, and hover using the existing `aden-graph` parser.

== Signature
|===
|Handler |LSP Method |Behavior

|`initialize`|Initialize|Registers textDocumentSync, definitionProvider, hoverProvider
|`did_open`|textDocument/didOpen|Stores document text, publishes diagnostics
|`did_change`|textDocument/didChange|Updates document text, re-publishes diagnostics
|`goto_definition`|textDocument/definition|Resolves `<<anchor>>` to file containing `[[anchor]]`
|`hover`|textDocument/hover|Returns `== Signature` table for referenced anchor
|===

== Invariants
. Diagnostics are published on every open and change event.
. Unresolved `<<refs>>` emit ERROR severity diagnostics.
. Missing `include::[]` targets emit ERROR severity diagnostics.
. Go-to-definition uses `AdenGraph::get_node` to locate the target file path.
. Hover extracts the first `Table` block with `Property | Value` headers.

== Agent Notes
agent-note::SIMPLIFICATION
No incremental sync (FULL sync only). No completion or rename. Rebuilds the graph from disk on every diagnostics request rather than maintaining an in-memory incremental index. Acceptable for Phase 5 MVP.
