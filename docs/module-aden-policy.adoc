= module::aden-policy

== Objective

Constitutional policy engine: directive precedence, conflict resolution, and `[constitution]` authority. Phase 0.7 of the Aden roadmap — the load-bearing security substrate.

== Signature

|===
|Type |Kind |Description

|`DirectiveSeverity`|enum|`Forbid`, `Warn`, `Suggest`, `Allow`.
|`DirectiveKind`|enum|`ForbidImport`, `RequirePattern`, `ContractConstraint`, `SelfModificationPolicy`, `Custom`.
|`Directive`|struct|A single directive with severity, kind, source tag, and attributes.
|`ConstitutionBlock`|struct|Parsed `[constitution]` block with `directives`, `precedence`, and `author`.
|`PolicyEngine`|struct|Holds loaded constitutions; resolves conflicts and evaluates actions.
|===

== Invariants

. `[constitution]` blocks must declare `:precedence:` or default to lowest priority.
. `[override]` blocks must contain `:justification:` and `:reviewer:`.
. `PolicyEngine::evaluate()` returns `Allow` when no constitution governs a subject.
. `Forbid` directives cannot be bypassed without a valid `[override]`.

== Agent Notes

agent-note::IMPLEMENTED
Precedence rules use numeric ranking: lower number = higher priority. Tie-breaking falls back to constitution author matching.
