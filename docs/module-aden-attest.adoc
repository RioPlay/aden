= module::aden-attest

== Objective

Attestation and signing primitives for Aden. Provides Ed25519 signing for cryptographic proof of provenance. This is distinct from the knowledge graph's internal dependency tracking.

== Signature

|===
|Type |Kind |Description

|`SignedAttestation`|struct|Signed payload with optional signature, public key, and timestamp.
|`ProvenanceRecord`|struct|Record of contract hash, source hashes, build metadata, and signer.
|===

== Functions

|===
|Function |Description

|`create_unsigned_attestation`|Create attestation with timestamp, no signature yet.
|`verify_signature`|Verify signature and public key are present.
|===

== Status

*Planned*: Signing primitives defined; Ed25519 implementation pending.
