[[module-aden-cli]]
= Aden CLI Reference

All aden CLI commands with quick reference and common workflows.

== Core Commands

=== init
Scaffold .agent/ templates in target repository.
[source,bash]
----
aden init [DIR]
----

=== new
Create new project from language template.
[source,bash]
----
aden new NAME --lang rust|go|js [DIR]
----

=== gen
Compile source into the knowledge graph (`.aden/store`); store-first, emits no files.
[source,bash]
----
aden gen PATH
aden gen .
aden gen . --quiet
----

=== regen
Recompile the whole project from scratch — alias for `aden gen .` that also clears `gen-cache.json` and the graph cache first. Use after a big merge or when caches may be stale.
[source,bash]
----
aden regen
aden regen .
----

=== check
Verify all refs resolve to existing anchors.
[source,bash]
----
aden check [DIR]
aden check . --severity Forbid
----

=== lint
Lint source files using fast, language-agnostic line-based heuristics.
[source,bash]
----
aden lint [PATH]
aden lint . --fix
aden lint . --severity Error
----

=== test
Discover and run tests across all languages.
[source,bash]
----
aden test [PATH]
aden test . --scope unit|integration|all
aden test . --list
aden test . --filter PATTERN
----

== Graph Queries

=== asm
Assemble context prompt from knowledge graph.
[source,bash]
----
aden asm --from ANCHOR
aden asm --from foo --depth 3 --budget 8192
aden asm --from bar --edge-types Uses,Calls
aden asm --from baz --silent
aden asm --from qux --inspect
----

=== query
Query graph and emit JSON.
[source,bash]
----
aden query --from ANCHOR
aden query --from ANCHOR --depth 2
aden query --backlinks ANCHOR
aden query --impact ANCHOR
----

=== ask
Natural-language question to subgraph assembly.
[source,bash]
----
aden ask "QUESTION" [DIR]
aden ask "QUESTION" --from ANCHOR
----

=== search
Full-text search across knowledge graph.
[source,bash]
----
aden search QUERY
aden search QUERY --limit 20
aden search QUERY --doc-type module|adr|plan
----

=== list
List all anchors and contracts.
[source,bash]
----
aden list
aden list --filter PATTERN
aden list --verbose
----

=== locate
Find symbol definitions or call sites.
[source,bash]
----
aden locate --symbol SYMBOL
aden locate --caller-of SYMBOL
----

=== grep
Flagship structure-aware content search: every match is tagged with the enclosing symbol resolved from the graph, so a hit doubles as an `aden asm --from <symbol>` entry point.
[source,bash]
----
aden grep "PATTERN"
aden grep --regex "\.parse\("
aden grep -i "todo"
aden grep "buffer" --symbol-only
aden grep "parse" --json
----

=== query-adq
Execute an Aden Query (`.adq`) script for advanced graph traversal with custom filters.
[source,bash]
----
aden query-adq script.adq
aden query-adq find-calls.adq --path src/
----

== Health and CI

=== heal
Self-healing documentation engine.
[source,bash]
----
aden heal .
aden heal . --propose
aden heal . --fix
aden heal . --gc
aden heal . --since REF
aden heal . --apply ID
----

=== doctor
Diagnose environment and repo health.
[source,bash]
----
aden doctor
aden doctor --verbose
----

=== ci-check
Run all local CI gates before committing.
[source,bash]
----
aden ci-check .
----

=== review
Semantic review with token budgeting.
[source,bash]
----
aden review [PATH]
aden review . --since REF
----

=== audit
OWASP-aligned security audit.
[source,bash]
----
aden audit [PATH]
aden audit . --lang rust
aden audit . --format json
----

=== status
Show project health at a glance: project path, active `.aden` store path, a health-score percentage (✅/⚠️/❌), and an orphan-document count. Takes only `[DIR]`. Gated behind the `watch` cargo feature.
[source,bash]
----
aden status
aden status .
----

=== sync
Run `gen` + `check` + `heal` in one pass — the recommended pre-commit sync.
[source,bash]
----
aden sync .
----

=== watch
Watch source files and auto-regenerate the graph on change.
[source,bash]
----
aden watch [DIR]
aden watch . --sync
aden watch . --graph-sync
aden watch . --restore
----

=== diagnose
Deterministic diagnostic scanner: missing source files, broken references, duplicate anchors, graph consistency.
[source,bash]
----
aden diagnose
aden diagnose --path .
aden diagnose --format json
----

== Session and Workspace

=== session
Atomic session lock for agents.
[source,bash]
----
aden session --agent-id ID --task DESC --status in_progress|completed
----

=== federation
Multi-repository workspace management.
[source,bash]
----
aden federation list
aden federation add PATH --name NAME
aden federation remove NAME
aden federation config
----

== MCP Integration

=== mcp install
Install aden MCP into AI platforms.
[source,bash]
----
aden mcp install
aden mcp install --platform opencode
aden mcp install --all
----

=== mcp uninstall
Remove aden MCP from platforms.
[source,bash]
----
aden mcp uninstall
aden mcp uninstall --platform opencode
----

=== mcp list
List supported platforms and status.
[source,bash]
----
aden mcp list
----

=== mcp serve
Start the MCP (Model Context Protocol) server for CI and agents.
[source,bash]
----
aden mcp serve --port 3030
----

The MCP server is a thin 1:1 bridge: each tool maps to an `aden` subcommand and
shells out to the CLI. It locates that binary via `ADEN_BIN`, then a sibling of
the running `aden-mcp` executable, then `PATH` — so set `ADEN_BIN` if `aden` is
installed somewhere non-standard. Like the CLI, every tool is language-agnostic
and operates on the target project, not on Aden itself.

== Utility Commands

=== kickoff
Create kickoff document for new initiative.
[source,bash]
----
aden kickoff --name NAME
aden kickoff --name NAME --interactive
----

=== workflow
Instantiate templates with substitutions.
[source,bash]
----
aden workflow kickoff|design|spec|task|adr
aden workflow kickoff --from FILE
aden workflow kickoff --out FILE
----

=== licenses
Generate third-party accreditation report.
[source,bash]
----
aden licenses
aden licenses --out NOTICE.md
----

=== emergency
Override severity level, auto-expires.
[source,bash]
----
aden emergency --reason REASON --ttl 24h
----

=== suggest
AI assistant: describe intent, get right command.
[source,bash]
----
aden suggest INTENT
----

== Global Options

[source,bash]
----
--unlimited   remove all limits
--json        output JSON where supported
--verbose     verbose output
-h, --help    help
----

== Troubleshooting

=== No contracts generated
----
aden gen . --auto --verbose
----

=== Broken references
----
aden check . --severity Forbid
----

=== Low health score
----
aden heal . --fix
----
