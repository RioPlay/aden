= module::aden-mcp

== Objective

MCP (Model Context Protocol) server for Aden. Exposes knowledge graph as MCP tools for Claude Code, Cursor, Zed, Windsurf, and other MCP-compatible AI agents.

== Status

*Shipped*: Thin CLI wrapper that invokes the `aden` binary over stdio. No graph pre-loading.

== Architecture

This is a thin wrapper. All business logic lives in the `aden` CLI. MCP tools map 1:1 to aden commands:

|===
|MCP Tool |aden Command |Description

|`list_symbols`|`aden parse`|List all symbols with anchors.
|`impact_analysis`|`aden query --backlinks`|Show what depends on a symbol.
|`context_for`|`aden asm`|Assemble token-budgeted context for a symbol.
|`ask`|`aden ask`|Natural language question answering.
|`search`|`aden search`|Full-text search across contracts.
|`asm`|`aden asm`|Context assembly with depth + budget.
|===

== Security

- No authentication (relies on stdio pipe from trusted agent).
- Tool names are hardcoded - no injection risk.
- Runs `aden` CLI as subprocess.

== Protocol

JSON-RPC 2.0 over stdio. Reference: https://modelcontextprotocol.io/specification
