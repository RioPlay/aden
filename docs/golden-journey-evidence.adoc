[[golden-journey-evidence]]
= Golden Journey Evidence

This record defines the reproducible DX-103 dogfood measurement. It does not
claim a median from one machine. CI proves the commands against a clean
repository; contributors may measure their local elapsed time with:

[source,bash]
----
scripts/measure_golden_journey.sh
----

The script creates a temporary committed repository, invokes the installed
`aden` binary for the documented `ask` → `understand` → `check` journey, and
prints elapsed seconds and command count. A release may claim the under-three-
minute median only after collecting multiple recorded runs with machine and
version notes. The installed `aden-mcp --version` smoke check is part of CI.

Developer observation: the journey needs no graph anchor and no repository
mutation. Agent observation: MCP receives structured receipt-bearing responses;
ambiguous symbols return candidates and recovery instead of a guessed anchor.
