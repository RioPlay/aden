[[golden-journey-evidence]]
= Golden Journey Evidence

This record defines the reproducible DX-103 dogfood measurement. CI proves the
commands against a clean repository; contributors may measure their local elapsed time with:

[source,bash]
----
scripts/measure_golden_journey.sh
----

The script can create an isolated installer output and a temporary committed repository, invokes the installed
`aden` binary for the documented `ask` → `understand` → `check` journey, and
prints elapsed time, command count, source provenance, and binary digest. The installed `aden-mcp --version` smoke check is part of CI.

Developer observation: the journey needs no graph anchor and no repository
mutation. Agent observation: MCP receives structured receipt-bearing responses;
ambiguous symbols return candidates and recovery instead of a guessed anchor.
