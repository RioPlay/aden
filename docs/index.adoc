== Quick Reference

=== Most Common Commands

[source,bash]
----
# Install (builds release; installs both `aden` and `aden-mcp` to ~/.local/bin)
./install.sh
# NOTE: `cargo install --path crates/aden-cli` installs ONLY the `aden` binary
# and silently omits the `aden-mcp` server. Use ./install.sh if you want MCP.

# Initialize a project
aden init

# Generate contracts from source
aden gen . --auto

# Validate the graph
aden check .

# Ask a question
aden ask "How does authentication work?"

# Detect drift
aden heal .

# Full CI gates
aden ci-check .
----
