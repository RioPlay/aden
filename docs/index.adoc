== Quick Reference

=== Most Common Commands

[source,bash]
----
# Install (builds release; installs both `aden` and `aden-mcp` to ~/.local/bin)
./install.sh
# NOTE: `cargo install --path crates/aden-cli` installs ONLY the `aden` binary
# and silently omits the `aden-mcp` server. Use ./install.sh if you want MCP.

# Compact map (reads auto-index; no init or project files)
aden tree --human --symbols .

# Structure-aware evidence and canonical symbol location
aden grep "SessionToken"
aden locate --symbol SessionToken

# One bounded question about a named subsystem
aden ask --human "Where is SessionToken validated?"

# Explicit backlinks / downstream impact
aden query --impact "aden://module/<crate>/<file>#SessionToken"

# Optional compatibility and methodology catalog
aden commands
----
