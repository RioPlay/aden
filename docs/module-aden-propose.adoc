= module::aden-propose

== Objective
Patch generation and proposal lifecycle management for drift events.

== Signature
|===
|Type/Function |Signature |Description

|`Proposal`|struct|id, target_path, drift_type, confidence, status, rationale, patch_asciidoc
|`ProposalStatus`|enum|PendingReview, Approved, Rejected, Applied
|`generate_patch`|`pub fn generate_patch(target_path: &Path, drift: &DriftEvent, document: &Document) -> Result<String, ProposeError>`|AsciiDoc-native patch
|`generate_stub`|`pub fn generate_stub(anchor: &str, title: &str, sig_table: &Table, source_hash: &str) -> String`|Minimal stub contract
|`persist`|`pub fn persist(proposal: &Proposal, store_dir: &Path) -> io::Result<PathBuf>`|Write to .aden/proposals/{id}.patch.adoc
|`load`|`pub fn load(id: &str, store_dir: &Path) -> io::Result<Proposal>`|Read back proposal
|`list`|`pub fn list(store_dir: &Path) -> io::Result<Vec<Proposal>>`|List all proposals
|`apply`|`pub fn apply(proposal: &Proposal) -> io::Result<()>`|Writes application (propose-only mode)
|===

== Invariants
. Every proposal carries :status: PENDING_REVIEW and :confidence: by default.
. Stub contracts include agent-note::STUB[Auto-generated by aden-heal. Review before removing this note.].
. Patch format is AsciiDoc-native, not unified diff, for human readability.
. Propose crate never mutates source files directly; only generates patches for review.
