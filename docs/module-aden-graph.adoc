= module::aden-graph

== Objective
Graph engine for the Aden knowledge graph. Builds `petgraph::DiGraph` from `.adoc`/`.aden` files, validates references, detects cycles, and injects backlinks.

== Signature
|===
|Type/Function |Signature |Description

|`AdenGraph`|struct|The Aden knowledge graph wrapping petgraph::DiGraph
|`DocumentNode`|struct|Node in graph: anchor, doc, parsed metadata, source_path

== Invariants
. Anchors must be unique across the graph. Duplicates are a hard error.
. `include::[]` edges are typed as `Requires`.
. `<<refs>>` edges are typed as `Uses`.
. Explicit `edge::` macros override default edge types.

== Agent Notes
agent-note::SIMPLIFICATION
Only parses a subset of AsciiDoc: header attributes, block anchors, `<<refs>>`, `include::[]`, `ifdef`/`ifndef`/`ifeval`, and custom `edge::` macros. Full AsciiDoc parsing is not required.
