= Phase 6: Enterprise Scale (Weeks 15–18)

== Objective

Organizational governance, spec-driven scaffolding, ecosystem integration.

== Theme

Organizational policy inheritance and federation across repositories.

== Deliverables

|===
|ID |Deliverable |Crate |Status |Acceptance Criteria

|6.1 |Organizational policy inheritance |`aden-policy` |Planned |`aden policy fetch` downloads templates; `aden policy update` suggests diffs; CI enforces inherited directives
|6.2 |`aden scaffold` from `[spec]` blocks |`aden-emit` |Planned |Produces module skeleton with pre-wired `[security]`/`[contract]`; lists required `[human]` blocks
|6.3 |`aden-api` REST/gRPC |`aden-api` |Planned |Query contract state, submit override proposals, export SBOM programmatically
|6.4 |`aden threat-model --report` |`aden-simulate` |Planned |Scans overrides; flags high-risk modules; exports HTML/JSON
|6.5 |Multi-repo federation (Phase 1) |`aden-graph` |Planned |Cross-repo edges via registry-published `.adg` artifacts
|6.6 |Post-quantum signing research (SPHINCS+) |`aden-attest` |Planned |Experimental; behind feature flag
|6.7 |Full A2A interoperability with third-party agents |`aden-a2a` |Planned |Aden-managed agents negotiate with external A2A agents via contract mediation
|===

== Exit Gate

Enterprise org with 50+ repos runs `aden policy fetch` from central template registry; CI enforces inherited `[constitution]` directives across all repositories.
