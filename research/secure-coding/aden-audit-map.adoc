[[aden-audit-map]]
= Aden Audit Findings ↔ Secure-Coding Graph

Maps the confirmed findings from aden's 2026-05-30 security audit onto the
weakness catalog (<<cwe-top25>>) and the mitigating practices
(<<scp-checklist>>). This is the cross-domain layer: it lets a query like
"backlinks of CWE-22" surface BOTH the mitigating practice AND aden's own
fixed finding, demonstrating relationship discovery across the corpus.

[[finding-mcp-path]]
== Finding HIGH-1 — MCP path argument escaped the project root
An MCP `path` argument could resolve to arbitrary host directories (read/write).
Weakness class: <<cwe-22>> (path traversal). Mitigated by <<scp-file-management>>
and <<scp-input-validation>>. Fixed by canonicalizing and confining the path to
the project root at the MCP boundary.

[[finding-arg-smuggling]]
== Finding MEDIUM-1 — Argument smuggling into the CLI
A leading-dash argument value was parsed by clap as a flag. Weakness class:
<<cwe-78>> (OS command injection family — argument injection). Mitigated by
<<scp-output-encoding>> (treat data as data) and an argv `--` terminator.

[[finding-parse-panic]]
== Finding HIGH-2/3/4 — Reverse byte-slice panic on `/**/`
An empty block comment caused an out-of-bounds slice, panicking the parser and
DoS-ing a whole `gen` run. Weakness classes: <<cwe-125>> (out-of-bounds read)
and <<cwe-400>> (uncontrolled resource consumption / DoS). Mitigated by
<<scp-memory-management>> (bounds checks) and a per-file catch_unwind boundary.

[[finding-path-leak]]
== Finding MEDIUM-2 — Absolute `$HOME` path leaked into context
Absolute source paths (with username) were persisted to the store and emitted
into LLM context. Weakness class: <<cwe-200>> (exposure of sensitive info).
Mitigated by <<scp-error-handling>> and <<scp-data-protection>>.

[[finding-secret-filter]]
== Finding INFO-1 — Content-blind secret filtering
The gen secret floor matches by filename/extension/directory, never content, so
a credential inside an ordinary config file is indexed. Weakness class:
<<cwe-798>> (hard-coded credentials) and <<cwe-200>>. Mitigated by
<<scp-data-protection>>; documented limitation, `.adenignore` recommended.

== Cross-cutting observation
Aden's confirmed findings cluster into three CWE families — path/input
(<<cwe-22>>), memory/DoS (<<cwe-125>>, <<cwe-400>>), and information exposure
(<<cwe-200>>) — and every one is covered by an existing OWASP secure-coding
practice in <<scp-checklist>>, validating the checklist as a release gate.
