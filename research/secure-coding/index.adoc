from authoritative public sources and wired together so aden can build a graph
of relationships between weaknesses, the practices that mitigate them, and
aden's own audited findings.

Sources: OWASP Secure Coding Practices Quick Reference Guide, OWASP Top 10:2025,
and the 2024 MITRE/CISA CWE Top 25.
